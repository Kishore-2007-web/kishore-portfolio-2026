# Lanyard Identity Card Texture Instructions

To update the 3D Lanyard ID Card texture:

1. Replace `card.png` in this directory (`src/assets/lanyard/card.png`) with your updated identity card texture image.
2. Recommended Aspect Ratio & Dimensions: `512px x 768px` or `1024px x 1536px` (2:3 aspect ratio).
3. Ensure the image is formatted as a PNG with transparent corners if rounded corners are desired.
4. Keep the same filename `card.png` or update the import path in `src/components/three/Lanyard.jsx`.
